# KxPlayer

KxPlayer is an Android media player built for smooth local playback, control, and modern media browsing.

## Features
- Local video and audio playback
- libmpv + AndroidX Media3 playback stack
- Material 3 interface
- Subtitle controls and advanced playback settings
- Background playback and media notifications
- Folder-based library browsing

## Tech stack
- Kotlin
- AndroidX Media3
- libmpv
- Jetpack Compose

## Build
```bash
./gradlew assembleDebug
```
